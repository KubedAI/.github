# Kubernetes + Data + AI = KubedAI 🚀

**Open-source tools and experiments for running Data and AI workloads on Kubernetes.**

KubedAI is an independent open-source initiative exploring **Kubernetes, distributed data, AI/ML infrastructure, GPU computing, and Agentic AI**.

Build useful things. Share what works. Learn together.
